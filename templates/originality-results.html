How the similarity score is calculated:
The system compares the proposed project with approved projects in the repository using Natural Language Processing (NLP) and cosine similarity.

The overall similarity score uses a weighted analysis:
  • Title: 35%
  • Keywords: 20%
  • Abstract: 45%

This weighting gives greater importance to the project title, keywords and abstract.

Important: This is a repository-based similarity assessment. It does not constitute universal plagiarism detection.
