Abstract

This project presents the design and development of an Intelligent Repository System aimed at improving originality in undergraduate research. The system provides students with access to previously approved projects through an organized digital repository, allowing them to search projects using titles and keywords.

The repository minimizes duplication of research topics, enhances accessibility to academic resources, and simplifies project submission through an administrator approval workflow. The system is developed as a web-based application capable of serving multiple faculties and departments within the university.
